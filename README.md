# Godziny Pracy

Natywna aplikacja Android do ręcznej ewidencji czasu pracy. Kalendarz jest ekranem głównym: dotknięcie dowolnego dnia otwiera edycję godzin „od–do” z systemowym wyborem czasu Androida.

## Funkcje

- miesięczny kalendarz z czasem pracy widocznym w każdym dniu,
- ręczne dodawanie, edycja i usuwanie wpisów,
- przerwy, zmiany nocne, urlop, zwolnienie i dzień wolny,
- historia wszystkich wpisów,
- podsumowania miesiąca, roku oraz pięciu lat,
- konfigurowalna dzienna norma i bilans nadgodzin,
- stawka ogólna i indywidualna stawka dla wybranego dnia,
- kopia danych w prywatnym obszarze aplikacji na Google Drive,
- opcjonalne powiadomienia o nowych wydaniach publikowanych na GitHub,
- lokalny zapis na telefonie bez konta i internetu,
- profesjonalny ciemny motyw.

## Uruchomienie

Otwórz folder w Android Studio i uruchom konfigurację `app` na emulatorze lub telefonie z Androidem 8.0 lub nowszym.

Z wiersza poleceń:

```powershell
.\gradlew.bat assembleDebug
```
